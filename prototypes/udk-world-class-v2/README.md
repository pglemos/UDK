# UDK World-Class V2 Static Prototype

Protótipo multipágina em HTML, CSS e JavaScript puro para aprovação visual antes da migração ao aplicativo Next.js.

## Abrir

Abra `index.html` diretamente no navegador. Não é necessário instalar dependências.

## Páginas

- Home
- Calendário
- Classificação
- Resultados
- Pilotos
- Perfil individual
- Notícias
- Página de notícia demonstrativa
- Regulamento
- Login
- Inscrição em etapas

## Validar

```bash
node scripts/validate-prototype.mjs
```

Este pacote não altera a produção da Vercel e não envia dados reais.
